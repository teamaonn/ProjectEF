# Fabric 26.2 EMC table prototype

The original ProjectEF Minecraft 1.21.1 source remains on the `mc1.21.1` branch. This fork's `fabric-26.2-emc-table` branch contains a focused Fabric 26.2 prototype under [`fabric-26.2/`](fabric-26.2/EMC-SHOP-README.md). It implements persistent per-player EMC, learned items, sales and purchases through a table/tablet screen. Original ProjectE textures and source are credited in the retained MIT license.

The 26.2 screen has been tested in singleplayer for the basic transaction loop, but this branch's repository copy still needs a full build and in-game check after its latest GUI layout change. This is not a full ProjectE port.
