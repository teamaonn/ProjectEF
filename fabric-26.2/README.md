# Fabric 26.3 EMC table prototype

This branch contains the focused Fabric 26.3 prototype under [`fabric-26.2/`](EMC-SHOP-README.md). It implements persistent per-player EMC, learned items, sales and purchases through a table/tablet screen. Original ProjectE textures and source are credited in the retained MIT license.

The 26.3 branch is based on the tested Fabric 26.2 table implementation. Build it from the `fabric-26.2` directory with Java 25:

```powershell
C:\Gradle\bin\gradle.bat build
```

This is not a full ProjectE port; it is the focused table/tablet EMC implementation we have been using.
